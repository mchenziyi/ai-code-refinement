# 规则来源与维护记录

## 阿里《Java 开发手册》

来源落地页：[泰山版](https://developer.aliyun.com/ebook/330)、[嵩山版](https://developer.aliyun.com/ebook/394)。两版是同源修订，主要可迁移的是问题机制：需求边界与异常流程（设计规约 §8）、职责/组合/抽象与共性复用（设计规约 §9–13）、公共接口兼容（OOP 规约 §4–5）、错误处理（异常处理 §1–4）、日志现场与重复输出（日志规约 §6–11）、自动/独立/可重复和边界/错误测试（单元测试 §1–9）、参数化输入和脱敏（安全规约 §1–5）。

这些条款是传统开发规范，不是 AI 专属要求。Javadoc、POJO、`@Override`、Java 异常控制流、`System.out` 的特定旧环境限制、Maven SNAPSHOT、MySQL/iBATIS、线程池和 `ThreadLocal` 等不能直接套用到 Python、TypeScript、Rust 或其他运行时。覆盖率数字也不能代替风险导向的集成验证。

## vArmor 项目规范

来源：[vArmor AGENTS.md](https://github.com/bytedance/vArmor/blob/main/AGENTS.md)，本轮资料读取时间为 2026-10-21；在线 `main` 未固定到不可变 commit，不能当作稳定版本承诺。它是 vArmor 项目规范，不代表字节全公司规范。

可迁移的是显式错误返回和上下文、结构化日志与 Secret 不入日志、成功/失败测试、输入入口校验加下游转义、并发共享状态与资源关闭、生成物和契约链核对。Go、Kubernetes、eBPF、Webhook、YAML 字符集、Kubernetes Secret 和 `make` 命令属于项目或技术栈专属案例。

## AI 特有缺口

传统规范不能解决需求理解、业务正确性、幻觉 API、上下文丢失、漏执行工具、伪造完成、自证偏差、环境依赖、并发协作和效果评测。手册只提供可借鉴的开发检查点；AI 流程还必须依据用户授权和项目约定记录实际证据。

## 2026-10-22 四种语言案例的来源记录

本轮实际读取以下官方页面的相关章节，用于核对 `references/通用规则与语言案例.md` 中的语言案例。它们是当前研究样本，不构成适用语言白名单；规则正文只保留可执行动作、触发条件、验证方式和必要例外。

- Go：[Effective Go](https://go.dev/doc/effective_go)、[Context](https://go.dev/blog/context)、[Go 1.13 Errors](https://go.dev/blog/go1.13-errors)、[Managing dependencies](https://go.dev/doc/modules/managing-dependencies)、[CancelFunc](https://pkg.go.dev/context#CancelFunc)。Effective Go 是较早的风格资料，不作为现代泛型或 module 事实的唯一依据。
- Python：[Exceptions](https://docs.python.org/3/library/exceptions.html)、[asyncio tasks](https://docs.python.org/3/library/asyncio-task.html)、[Python 3.14 cancellation](https://docs.python.org/3.14/library/asyncio-task.html#task-cancellation)、[contextlib](https://docs.python.org/3/library/contextlib.html)、[typing](https://docs.python.org/3/library/typing.html)。
- Node.js：[Don't block the event loop](https://nodejs.org/en/learn/asynchronous-work/dont-block-the-event-loop)、[Errors](https://nodejs.org/api/errors.html)、[Streams](https://nodejs.org/api/stream.html)、[Packages](https://nodejs.org/api/packages.html)、[AbortController](https://nodejs.org/api/globals.html#class-abortcontroller)。Node.js 例子针对 JavaScript/TypeScript 项目，具体 Node 版本和 TypeScript 工具链仍以项目配置为准。
- Rust：[Ownership](https://doc.rust-lang.org/book/ch04-00-understanding-ownership.html)、[Error handling](https://doc.rust-lang.org/book/ch09-00-error-handling.html)、[Concurrency](https://doc.rust-lang.org/book/ch16-00-concurrency.html)、[Shared state](https://doc.rust-lang.org/book/ch16-03-shared-state.html)、[Smart pointers and Drop](https://doc.rust-lang.org/book/ch15-00-smart-pointers.html)、[Why Cargo exists](https://doc.rust-lang.org/cargo/guide/why-cargo-exists.html)。Rust 异步运行时不属于标准库默认能力。

来源页面读取时间为 2026-10-22，页面版本可能漂移；来源事实与通用开发动作的边界以 runtime reference 的具体条目为准。没有做四种语言真实应用工程、benchmark 或 A/B 对照，不据此宣称减少缺陷。
